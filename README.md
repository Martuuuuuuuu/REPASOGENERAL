## Descripción

Este proyecto corresponde a la Actividad 6 de Laboratorio de Programación. Su objetivo es repasar y consolidar los conocimientos de C++ mediante la resolución de tres retos prácticos relacionados con la recursividad, la búsqueda secuencial en arreglos y el uso de punteros.

## Retos

1. **Reto 1: Suma recursiva.** Implementación de una función recursiva que calcula la suma de los números desde 1 hasta un valor determinado, utilizando un caso base para detener las llamadas.

2. **Reto 2: Búsqueda secuencial.** Recorrido de un arreglo de números enteros para localizar un valor específico, mostrando su índice y dirección de memoria. Se utiliza `break` para interrumpir el ciclo cuando se encuentra el elemento.

3. **Reto 3: Intercambio de valores mediante punteros.** Intercambio de los valores de dos variables mediante sus direcciones de memoria, utilizando punteros y una variable temporal.

## Estructura del repositorio

- `src/`: contiene el código fuente del programa.
- `docs/`: contiene la documentación de la actividad y el registro de cambios.
- `docs/manuales/`: contiene los manuales del programador y del usuario.
- `capturas/`: contiene las evidencias de ejecución.
- `.gitignore`: establece los archivos y carpetas que Git debe ignorar.
- `LICENSE`: contiene la licencia del proyecto.
- `README.md`: presenta y describe el proyecto.
